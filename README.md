# dashboard-financeiro-pessoal-excel
Dashboard financeiro pessoal desenvolvido em Excel

## Sobre
Projeto desenvolvido em Microsoft Excel para controle de gastos pessoais e visualização de indicadores financeiros.

## Funcionalidades
- Registro de receitas e despesas
- Resumo mensal automático
- Dashboard financeiro
- Controle de saldo mensal
- Análise de despesas por categoria
- Visualização gráfica dos dados

## Ferramentas utilizadas
- Microsoft Excel
- Fórmulas: SOMA, SOMASE, CONT.VALORES e cálculo de porcentagem
- Tabela e organização de dados
- Dashboard visual

## Objetivo
Praticar Excel e desenvolver um projeto para demonstrar habilidades em análise de dados e criação de dasboards.
